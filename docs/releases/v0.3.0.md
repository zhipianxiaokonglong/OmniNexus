# OmniNexus 0.3.0（历史版本）

> 0.3.0 之后的默认提供方修复已并入 [0.3.1](v0.3.1.md)。

发布日期：2026-11-03（默认提供方 hotfix：2026-11-05）

## 重点

- Emotion contract v2（12 类），与下游语音/表达层标签对齐。
- 引用 URL 默认不再写入正文，避免 TTS 朗读链接。
- session 信号更明确：`session_created`、`legacy_session_id`；`metadata.session_id` 兼容回退并告警。
- 默认模型不可用时优先使用默认厂商的已配置模型。
- **Hotfix 2026-11-05**：设置页默认提供方/模型现在会真正作用于新建会话，不再被
  `gateway.default_model` 遮蔽（Dounai 审计）。

## 升级说明

- 下游若仍只接受旧 9 类：增加别名 `fear→sadness`、`confusion→frustration`、`gratitude→joy`。
- 若依赖正文里的“参考来源”附录：设置 `gateway.citations_in_content: true`。
- 客户端应把 `session_id` 放事件顶层；metadata 内的旧写法仅兼容。
