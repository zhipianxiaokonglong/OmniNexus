# OmniNexus 0.3.3

发布日期：2026-11-07

## 修复

### 旧会话兼容（A1 残留）

0.3.1 修复了新会话不使用设置默认的问题，但 **0.3.1 之前创建、拆分字段为 NULL 的旧会话**
仍会在提供方不可用时返回 409。

0.3.3 的处理：

| 旧会话状态 | 行为 |
|---|---|
| 无模型回答（空会话） | 自动迁移到当前可用默认，`meta.recovered_default=true` |
| 已有模型回答 | **保持原模型**，不静默迁移；返回可读 409 |
| 显式创建（拆分字段已填） | 即使提供方被禁用也不自动改写 |

409 现在包含：

```json
{
  "error": {
    "code": "PROVIDER_UNAVAILABLE",
    "message": "当前会话使用的模型 openai:gpt-4o-mini 不可用（该提供方未配置密钥）。可在聊天页切换到 custom:…:my-model，或使用旧会话迁移向导。",
    "details": {
      "reason": "provider_not_configured",
      "current_model": "openai:gpt-4o-mini",
      "suggested": {"providerKind": "custom", "providerId": "…", "model": "my-model"}
    }
  }
}
```

### 错误体补齐 `request_id`

`OmniError` 响应体现在包含 `request_id`，与 `X-Request-ID` 一致，错误契约字段齐备。

## 新增

### `GET /v1/contract`

只读、无副作用、不含密钥的机读契约清单：

```json
{
  "service": "omninexus",
  "service_version": "0.3.3",
  "contracts": {
    "event": {"version": "1.0", "required_fields": ["event_id", "session_id", "content", "stream", "tags"]},
    "emotion": {"version": "2", "labels": ["…12 类…"], "legacy_aliases": {"fear": "sadness"}},
    "memory": {"version": "1.0", "status": "reserved", "default_enabled": false},
    "error": {"version": "1.0", "fields": ["code", "message", "retryable", "details", "request_id"]}
  },
  "compatibility": {"policy": "major_reject_minor_degrade"}
}
```

### `/v1/healthz` 版本字段

```json
{"status": "ok", "service_version": "0.3.3", "contract_version": "1.0", "tag_contract": "2"}
```

## 明确的两个决策

1. **版本语义分离**：`service_version` 是包版本，每次发布都会变；`contract_version`
   只在破坏性契约变更时变。消费方不应把二者混用。
2. **情绪以 12 类为准**：`/v1/contract` 的 `contracts.emotion.labels` 是唯一权威列表；
   9 类是历史版本，消费方通过 `legacy_aliases` 映射，不要求生产方收敛。

不兼容策略：**主版本拒绝，次版本降级并告警**（`major_reject_minor_degrade`）。
