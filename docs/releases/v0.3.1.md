# OmniNexus 0.3.1

发布日期：2026-11-05

## 修复

**设置页的默认提供方/模型现在会真正作用于新会话。**

Dounai 审计发现：新建会话时只传 `model=None`，`SessionService` 因此把静态
`gateway.default_model` 写入会话；随后模型选择逻辑优先读取会话字段，用户设置的
`/v1/provider-defaults` 永远不生效。

0.3.1 的修复：

- 创建会话前先读取用户默认，并同时持久化 `provider_kind/provider_id/model_name` 与
  canonical `model`；
- 保证新旧字段一致；
- 历史会话保持原样、不静默迁移；提供方不可用时仍返回 `409 PROVIDER_UNAVAILABLE`；
- 新增回归测试覆盖报告中的完整复现路径。

## 升级

通常无需迁移数据：

```bash
python -m pip install -e .
python -m pytest -q
python -m omninexus
```

升级后**新建会话**会使用设置页默认；已有会话继续使用其历史模型。若历史会话的提供方已不可用，
请在设置页的旧会话迁移向导中显式迁移，或直接在聊天页重新选择。
